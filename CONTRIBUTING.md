# Contributing to OpenWP

Thanks for helping. Bug reports, questions and ideas are welcome in [Discussions](https://github.com/AiNextStudioIT/openwp/discussions) and [Issues](https://github.com/AiNextStudioIT/openwp/issues). For a code change, open an issue or a discussion first, so we can agree on it before you spend time.

## Pull requests

- Keep each pull request small and about one thing.
- Say which WordPress version, builder (Elementor, Bricks, Divi, Gutenberg) and AI client you tested with.
- Do not include secrets, real site addresses or personal data in code, tests or screenshots.
- Layout changes must keep the backup and restore path working.
